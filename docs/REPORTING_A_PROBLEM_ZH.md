# 报告问题

muxing 出错时，tsMuxeR 生成的两个文件有助于查找故障，无需发送整部影片：

| 文件 | 内容 | 大小 | 何时发送 |
|---|---|---|---|
| **报告** | 一个记录本次运行的文本文件：tsMuxeR 收到了什么、每条消息、每条轨道读取和舍弃了什么，以及写入了什么 | 很小 | 任何问题都发送 |
| **样本** | 一个 .zip 文件，内含逐字节复制的一部分源文件 | 最大 25 MB | 报告不够用时，或被要求提供时 |

两者都可以在窗口或命令行中生成。请使用 ["Bug report" 表单](https://github.com/teaching-droid/tsMuxer/issues/new/choose)新建 issue 并附上它们。文件可以直接拖入表单。

**issue 是公开的。** 报告不包含任何画面或声音，并会替换您的文件名。样本包含影片本身的一部分，因此只有在您可以分享时才附上。

## 在窗口中操作

### 生成报告

1. 打开 **常规** 选项卡，勾选 **为每次 muxing 写入报告，用于问题报告**。
2. 再次运行任务，让问题出现。
3. 任务结束后，在进度窗口中点击 **保存报告...**。
4. 阅读显示的内容，然后保存。

### 生成样本

1. 在 **导入** 选项卡的列表中选择文件，然后点击 **制作样本...**。任务因错误结束时，进度窗口也会提供此功能。
2. 在 **截取** 下选择 **开头**、**结尾** 或 **此时间附近（问题所在处）**，并填写时间。
3. 在 **尺寸** 下保留给出的大小，或选择更小的值。.zip 文件会保持在 25 MB 以下。
4. 如果有上一个任务的报告，请勾选 **添加上一个任务的报告**。**显示报告** 可以先查看它。
5. 在 **另存为** 下选择 .zip 文件的位置，然后点击 **制作样本**。

## 在命令行中操作

为出错的任务加上 `--report`：

```
tsMuxeR --report=report.txt film.meta film.ts
```

然后在问题发生的时间附近制作样本，并把该报告放进去：

```
tsMuxeR --make-sample --at=1:02:13 --add-report=report.txt film.mkv sample.zip
```

| 选项 | 作用 |
|---|---|
| `--from-start` | 截取源文件的开头。这是默认值。 |
| `--from-end` | 截取源文件的结尾。 |
| `--at=<时间>` | 截取某个时间附近的部分，格式为 h:mm:ss 或秒数。 |
| `--size=<MB>` | 设置样本大小，范围为 1 到 24 MB。未指定时为 20。 |
| `--add-report=<文件>` | 把出错任务的报告放入 .zip 文件。 |

报告的名称不能与任务中的文件相同：源文件、.meta 文件或输出文件。样本也不能覆盖其源文件或要放入其中的报告。tsMuxeR 会拒绝这些名称并给出提示。

## 报告包含的内容

* tsMuxeR 的版本和系统信息：系统版本、处理器数量、内存和运行时间
* 命令行和 .meta 文件
* 每个源文件的大小、前 32 个字节及其列表
* 运行中的每条消息及其时间（秒），包括屏幕上不显示的行
* 每条轨道读取、使用和舍弃的内容
* 写入的文件及其大小

**您的名称不会公开。** 所有路径中的文件夹都会被去掉。文件、标题、轨道和章节的名称会被替换为占位符，例如 `<source1>.mkv`。名为 Names 的部分只给出查找名称相关故障所需的信息，例如长度和是否含有空格。光盘内的文件名（例如 `00011.mpls`）会保留。

只有在被要求时才使用：`--report-keep-names` 保留名称，`--report-full-paths` 同时保留文件夹。`--report-frames` 会增加第二个大得多的文件，其中写入的流的每一部分占一行。请为它指定时间范围，例如 `--report-frames=0:10:00-0:12:00`。

## 样本包含的内容

* **一部分源文件**，逐字节复制，因此会出现与源文件相同的故障
* **制作样本的报告**，如果您添加了任务的报告，也包含在内

在 .zip 中，该文件名为 `source1`，后跟其原有扩展名。Matroska 样本保留轨道和章节，但其标题以及轨道和章节的名称会被清空。标签、附件和索引不包含在内。

样本从可以开始读取的位置开始，因此可能比您指定的时间稍早。能放入样本的源文件会被完整截取，指定的时间超过结尾时则截取结尾。

部分源文件有以下限制：

| 源文件 | 限制 |
|---|---|
| MP4、MOV | 只能截取开头，`--at` 和 `--from-end` 会被拒绝。 |
| 单独的视频流 | 不含时间信息，请截取开头或结尾。 |
| 光盘映像内的文件 | 在映像后写出路径，例如 `film.iso/BDMV/STREAM/00001.m2ts`。 |

各类源文件的详细说明，请参阅 [USAGE](USAGE.md) 中的 "Sample for a problem report"（英文）。

## 其他有帮助的信息

* 您预期的结果，以及实际发生的情况
* 如果是播放问题，请说明所用的播放器或设备

报告已包含版本、.meta 文件和完整日志，因此有报告时无需再粘贴这些内容。
